
#  Product Count Analysis using Excel

##  Project Overview

This project is part of the VEDA Technology Internship – Data Analytics Track.

The objective of this task is to count products by category using Microsoft Excel and identify the category with the highest number of products.

## Objective

- Count products category-wise.
- Practice the COUNTIF function.
- Identify the largest product category.
- Create a bar chart for data visualization.

##  Tools Used

- Microsoft Excel
- COUNTIF Formula
- Excel Charts
- Data Analysis

##  Dataset Information

The dataset contains 30 products divided into 5 categories.

| Column | Description |
|--------|-------------|
| Product ID | Unique ID of each product |
| Product Name | Name of the product |
| Category | Product category |

##  Product Count Analysis

| Category | Product Count |
|----------|--------------|
| Electronics | 7 |
| Stationery | 6 |
| Furniture | 6 |
| Kitchen | 6 |
| Bags | 5 |

##  Excel Formula Used

### COUNTIF Formula

The COUNTIF function was used to count products by category.

**Formula:**

```excel
=COUNTIF('Product Data'!C:C,A2)
```

### Formula Explanation

- `'Product Data'!C:C` → Category column in the Product Data sheet.
- `A2` → Category name to be counted.
- The formula counts the number of products belonging to each category.

The formula was applied to the category list to calculate product counts.

##  Top Category

Based on the product count table, Electronics is the category with the highest number of products.

| Item | Result |
|------|--------|
| Top Category | Electronics |
| Product Count | 7 |
